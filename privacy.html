PRIVACY POLICY

개인정보처리방침

시행일: 2026년 8월 31일

1. 적용 범위

본 방침은 개인적으로 운영하는 “Hermes Google Integration”(이하 “애플리케이션”)이 Google OAuth를 통해 처리하는 사용자 데이터에 적용됩니다.

2. 처리하는 정보와 목적

  • Gmail: 사용자가 요청한 메일 검색·조회·정리·발송·답장 및 라벨 관리
  • Google Calendar: 일정 조회·생성·수정·삭제
  • Google Tasks: 할 일 목록 조회·생성·수정·완료 처리
  • 기본 계정 정보: OAuth 승인 계정 식별과 연결 상태 확인

위 정보는 사용자가 직접 요청한 생산성 작업을 수행하기 위해서만 처리합니다.

3. 저장 및 보관

OAuth 토큰은 운영자가 관리하는 Hermes Agent 실행 환경의 로컬 저장소에 보관됩니다. 작업 결과와 대화 기록은 사용자가 요청한 기능 제공 및 연속성 유지를 위해 필요한 범위에서만 보관합니다. Google 계정 비밀번호는 수집하거나 저장하지 않습니다.

4. 제3자 제공 및 판매

Google 사용자 데이터를 판매하지 않으며 광고, 신용평가 또는 제3자 프로파일링에 사용하지 않습니다. 사용자의 명시적 요청, 법적 의무 또는 기능 수행에 필수적인 서비스 제공을 제외하고 제3자에게 제공하지 않습니다.

5. 보안

접근 권한 최소화, 로컬 자격증명 보호, 승인된 사용자만의 접근 및 불필요한 외부 공유 제한을 적용합니다. 사용자는 언제든 Google 계정의 보안 설정에서 애플리케이션 접근 권한을 철회할 수 있습니다.

6. 삭제 및 철회

사용자는 Google 계정의 ‘서드 파티 앱 및 서비스’에서 OAuth 권한을 철회할 수 있습니다. 저장 데이터나 연결정보 삭제를 요청하면 법적 보존 의무가 없는 범위에서 지체 없이 삭제합니다.

7. Google API 정책 준수

Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 준수합니다.
